## 各章时长（目标与实际）

「目标」来自 `m3-plan.md` 与 `chapters-7-9-plan.md`；「实测」是 `npm run sim` 跑出来的纯挂机时长（每职业的种子数见各章进度，第 7 章 3 个、第 8～9 章 8 个）。任务经验约占升级所需四成，实际通关会比纯挂机短。

## 55～70 级

`npm run sim -- 70` 能跑，但**现在没有参考价值**：新地图没做，55 级以后只能在镇魔塔挂机，等于用一张 50 级图刷到 70 级。等第 10～12 章逐章落地后，每章做完重跑一次，再回到本表补实测数字。

1→70 纯挂机的粗略外推是 70～90 小时（第 9 章末尾已有 56/58/38 小时的 1→55 基线，后 15 级还要加每级 7% 的曲线），这是 `chapters-10-12-plan.md` 里的主要风险。
