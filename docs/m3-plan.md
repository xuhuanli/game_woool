# M3 内容与剧情计划

M3 的目标是 1～40 级可以从头玩到结局。先验证美术，再补内容底座，然后逐章制作，最后全程通关验证。

## 已定决策

| 问题 | 决定 |
| --- | --- |
| 美术路线 | 先做 1 个角色验证 8 方向序列帧，走不通就改用商用素材包 |
| 境界节奏 | 练气到 13 级，血色禁地是练气后期副本，在此夺药并突破筑基 |
| 主线深度 | 每章 5～8 个主线任务，由 Claude 写初稿，作者审核人物和原著细节 |
| 游戏名称 | 暂不定，继续用“修仙传奇（暂定）” |

## 内容规模

按 6 章估算，主线任务 30～48 个。每章还需要 1 张主要地图、3～4 种常规怪和 1 个以上 Boss。

## 现有实现要改的地方

- **开局位置**：剧情从第 1 章的七玄门开始，现在的代码从黄枫谷开始。
- **主城**：设计文档按章切换七玄门、黄枫谷、天星城、落云宗，底座已支持，现在只配了黄枫谷一张。
- **筑基丹**：现在靠铁甲蛟 25% 掉落。改成第 3 章的剧情必得，同时解决卡关风险。
- **任务内容**：M2 的 5 个任务、铁甲蛟和部分 NPC 都是系统演示内容，会被章节内容替换。
- **挂机与 Boss**：设计文档要求打 Boss 由玩家手动完成，第 3 批要确认每章 Boss 单人可打。

## 美术验证

`assets-src/` 里的 Poly Haven 模型是 CC0 的岩石、植物和道具，适合渲染成场景素材，不含人物。game-icons 是 CC BY 3.0，公开发布时需要署名，可用于技能和物品图标。

第 0 批走的是 3D 预渲染：`tools/bake/cultivator.ts` 用代码搭模型和动作，`tools/bake/bake.ts` 从 8 个方向渲染成精灵表，输出到 `public/assets/sprites/`。启动 `npx vite --config tools/bake/vite.config.ts` 后打开 http://localhost:5180 即可重新烘焙。

目前只烘焙了体修，其他职业、怪物和 NPC 仍是占位图。AI 生成序列帧没有验证，因为它消耗付费点数，且难以保证 8 方向一致。

## 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 8 方向序列帧走不通 | 需要重买素材，甚至改视角 | 第 0 批先验证，失败立即转商用素材包 |
| 六章文案量大 | 时间拉长 | 先做第 1 章模板，据实估算 |
| 剧情资料是二手内容 | 人物和细节可能有误 | 每章由作者对照原著审核 |
| 40 级数值没有模拟依据 | 后期可能过快或过难 | 第 1 批扩展经验表，每章完成后重跑模拟 |
| 手动产出没有模拟 | 挂机和手动的差距不明 | 第 9 批按试玩结果调整 |
